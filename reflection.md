# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think compute resources are one of the most important components because they provide the processing power needed to run applications and services. Without compute resources, cloud workloads cannot function properly.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by managing CPU, memory, storage, and networking resources. In this laboratory, I used Linux commands in KillerCoda to examine the resources of a cloud-based server.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation helps engineers understand the system and record important configurations and decisions. It also makes troubleshooting and future improvements easier.

## 4. What new skills did you learn during this laboratory activity?

I learned how to use Linux commands such as `lscpu`, `free -h`, `df -h`, `hostname`, and `hostname -I`. I also learned how to create Markdown documentation, compare cloud services, and organize files using GitHub.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio became more organized after adding the cloud infrastructure project. I also improved my skills in documentation, file organization, screenshots, and GitHub commits.

## Conclusion

This laboratory helped me understand the basic components of cloud infrastructure and how they work together. It also taught me the importance of Linux, documentation, and proper organization when working with cloud systems.
