# Cloud Provider Comparison

AWS, Microsoft Azure, and Google Cloud offer similar cloud infrastructure services with different product names.

| Component  | AWS     | Azure            | GCP            |
| ---------- | ------- | ---------------- | -------------- |
| Compute    | EC2     | Virtual Machines | Compute Engine |
| Storage    | S3      | Blob Storage     | Cloud Storage  |
| Networking | VPC     | Virtual Network  | VPC            |
| IAM        | AWS IAM | Entra ID / RBAC  | Cloud IAM      |

## Guide Questions

**1. Which provider offers the broadest range of services?**
AWS offers a very wide range of services, including computing, storage, networking, databases, security, and AI.

**2. Which platform is best for organizations using Microsoft products?**
Azure is a good choice because it integrates well with Microsoft products and services.

**3. Which platform is known for AI, ML, and Kubernetes?**
Google Cloud is widely known for its AI, machine learning, and Kubernetes capabilities.

**4. What similarities do they have?**
All three provide scalable compute, storage, networking, and identity services for cloud applications.
