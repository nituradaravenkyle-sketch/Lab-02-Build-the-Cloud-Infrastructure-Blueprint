# Cloud Infrastructure Components

## 1. Compute Resources

**Example:** Intel Xeon CPU, 1 core, and 1.9 GiB RAM.
**Purpose:** Provides processing power and memory for applications.
**Cloud Importance:** Allows workloads to run and scale when needed.
**KillerCoda:** The Linux server uses its CPU and RAM to run commands and applications.

## 2. Storage Resources

**Example:** 19 GB `/dev/vda1` disk using ext4.
**Purpose:** Stores system files, applications, and data.
**Cloud Importance:** Provides reliable space for storing information.
**KillerCoda:** The server uses `/dev/vda1` as its main storage.

## 3. Networking Resources

**Example:** IP address `172.30.1.2`.
**Purpose:** Allows devices and services to communicate.
**Cloud Importance:** Connects cloud resources and users.
**KillerCoda:** The Linux server uses its IP address for network communication.

## 4. Operating System

**Example:** Ubuntu 24.04.4 LTS with Linux kernel `6.8.0-136-generic`.
**Purpose:** Manages hardware and runs applications.
**Cloud Importance:** Provides the environment needed for cloud workloads.
**KillerCoda:** Ubuntu is the operating system running on the cloud server.

## Conclusion

Compute, storage, networking, and the operating system work together to provide a functional cloud infrastructure.
